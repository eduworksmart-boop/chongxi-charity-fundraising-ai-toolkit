## 參、公私信函撰寫五大安全禁忌（踩坑防範）

1. **體例錯誤（切勿公文八股）**：
   - 向民間企業與基金會董監事發信，採用溫暖、真摯的私人信函體。絕不可使用「主旨、說明、辦法」等僵化公文格式。
2. **標籤化禁忌（絕對不用「偏鄉」二字）**：
   - 吳校長與學校堅持尊重學童主體自信。文中一律使用「鄉村地區」、「鄉下農村」或「鄉村學校」，絕不可寫「偏鄉」，不販賣悲情。
3. **公庫結餘款保密原則**：
   - 信函焦點置於「教育現場實質短缺」與「孩子課照需求」，絕不主動提及公庫歷年累計結餘款數字。
4. **去個人化原則**：
   - 絕不可在正式對外文稿中提及基金會個別承辦人的私人姓名或私人通話內容，一律尊稱「董事會各位先進」、「貴基金會」。
5. **列印裁切防範（單頁極簡）**：
   - 實體印表機邊界需維持 16mm 以上，請統一套用 `templates/` 目錄下的標準公版（頂端邊界 3.5cm），切勿隨意縮減邊界導致吉祥物羽冠被裁切。
